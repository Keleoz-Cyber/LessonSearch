# 查课计划使用说明

## 概述

查课计划让你提前排好本周或未来几周的查课任务，在上课前 15 分钟通过系统通知栏提醒你，避免忘记查课。

**数据完全本地存储**，不经过任何第三方服务器，学生信息安全。

## 快速入口

首页 → 二级入口「查课计划」（📋 图标，第一行第一位）

## 首页内容

### 查看计划列表

- 计划按**周次分组**，每组内按**星期+节次**排序
- 每张卡片显示：星期几、第几节、班级名、日期时间、教室
- 右上角状态标签：
  - 🟢 **已设提醒** — 正常，会上课前 15 分钟通知
  - ⚪ **提醒已关** — 计划还在，但不会通知
  - ⚪ **已结束** — 上课时间已过

### 长按卡片操作

长按任意计划卡片，弹出底部操作菜单：
- **切换提醒** — 开启/关闭该计划的课前通知
- **删除** — 删除该计划（同时取消对应的通知）

## 创建计划

点击右下角 **+ 新建** 按钮进入创建页。

### 第 1 步：选择周次

默认显示当前周次。点击 **− / +** 调整到目标周次（如第 2 周、第 3 周）。

### 第 2 步：选择星期

点击周一到周五的 chip，选择要查课的星期。

### 第 3 步：选择节次

点击 8 节课中要查的那一节。每节显示上课时间范围：

| 节次 | 上课时间 |
|---|---|
| 第 1 节 | 08:30 - 09:15 |
| 第 2 节 | 09:20 - 10:05 |
| 第 3 节 | 10:25 - 11:10 |
| 第 4 节 | 11:15 - 12:00 |
| 第 5 节 | 14:30 - 15:15 |
| 第 6 节 | 15:20 - 16:05 |
| 第 7 节 | 16:25 - 17:10 |
| 第 8 节 | 17:15 - 18:00 |

### 第 4 步：选择班级

点击「选择班级」卡片，弹出班级选择对话框：

1. **筛选**：顶部两行横向 chip
   - 第一行：按**年级**筛选（如 2024 级、2023 级）
   - 第二行：按**专业**筛选（如 软工、计科）
   - 点击「全部年级/专业」清除筛选
2. **选择**：下方按筛选结果分组显示班级名称，点击即可选中/取消
3. **已选预览**：顶部蓝色条显示当前已选班级，点击右侧 ❌ 可清除全部
4. 点击「完成」关闭对话框

### 第 5 步：填写教室

输入教室编号，如 `4213`、`A301`。**必填**。

### 第 6 步：填写备注（可选）

如"重点查课"、"配合班主任"等。

### 第 7 步：确认创建

底部预览区会显示：
- 上课时间：如 `6月23日 08:30`
- 提醒时间：如 `6月23日 08:15`（上课前 15 分钟）

确认无误后，点击底部 **「创建并设置提醒」** 按钮。

首次使用会弹出通知权限请求，请选择「允许」。如果拒绝，计划仍会保存，但不会收到提醒。

## 通知权限

如果之前拒绝了通知权限：
- 可以在列表页右上角点击 🔔 图标，手动请求权限
- 或在系统设置 → 应用 → 考勤助手 → 通知中开启

## 注意事项

1. **一次只能排一节查课**。如果一周需要查多节课，需要创建多条计划。
2. **提醒时间已过不会发送通知**。如果创建时提醒时间已经过去，计划仍会保存但不通知。
3. **数据本地存储**，卸载 App 会丢失。如需长期保存，建议截图或导出。
4. **周次与学期联动**，周次来自后端返回的当前学期 r。如果学期切换，需要重新创建计划。
5. **通知可能被系统拦截**，部分手机（华为/小米/OPPO/vivo）的省电模式可能禁止通知。建议在系统设置中将考勤助手加入白名单。
