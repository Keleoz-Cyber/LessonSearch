# 考勤助手 v0.7.1

Android 正式版，版本号 **0.7.1**，构建号 **35**。

## 更新内容

- 修复任务恢复、撤销、并发提交、失败重试和账号切换后的本地数据隔离。
- 历史记录、提交、周汇总、排行榜与导出按学期隔离，保留旧学期数据。
- 当前学期为 **2026-2027第一学期**，开学日期 **2026-08-31**。
- 完善系统通知权限、提醒状态、设备重启后的提醒恢复及通知跳转。
- 修复窄屏布局、加载/错误状态和交互流程，适配系统减少动画设置。
- 统一设置页、关于页、诊断和公告版本；更新检查不再误提示降级，只返回实际发布的 APK 下载地址。
- 增加客户端与服务端回归测试、生产配置校验、备份及迁移预检。

## 安装与提醒说明

请下载本发布页附件中的 `kaoqin-helper-v0.7.1.apk`，直接覆盖安装。**不要先卸载旧版**，以免丢失尚未同步的本地数据。

Android 提醒需要通知权限；精确闹钟权限和厂商省电设置会影响准时性。在系统设置中“强行停止”应用后，需要重新打开应用才能恢复提醒。实时通知的展示形式受 Android 版本和厂商支持影响，不保证所有设备都有同样的状态栏效果。

本次正式安装包为 Android APK，不提供未签名 iOS 包。历史版本日志仍可在应用设置和 CHANGELOG 中查看。
